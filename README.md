# 💖 Love Gacha - Website Gacha Hadiah Pasangan

Website gacha statis (HTML, CSS, JS) yang siap di-host gratis menggunakan **GitHub Pages**.

## 🎁 Daftar Hadiah & Drop Rate
1. **🧸 Boneka Lucu** (SSR - 10%)
2. **💸 Transfer Uang Rp 100.000** (SSR - 10%)
3. **💎 Top Up 400 Robux** (SR - 15%)
4. **💵 Transfer Uang Rp 50.000** (SR - 20%)
5. **🍦 Beli Es Krim** (R - 25%)
6. **📸 ZONK! Wajib Kirim PAP** (ZONK - 20%)

## ✨ Fitur Seru
- **Sistem Pity (5x Pull):** Dijamin dapat hadiah **SSR** (Transfer 100K atau Boneka) pada tarikan ke-5.
- **Tas Hadiah & Kode Klaim Unik:** Setiap hasil gacha tercatat lengkap dengan kode klaim (contoh: `LOVE-4821`) dan tombol salin pesan otomatis untuk dikirim ke WhatsApp.
- **Sistem Tiket & Kode Rahasia:** Pasangan mulai dengan **3 Tiket** dan bisa menambah tiket lewat klaim harian atau memasukkan kode rahasia (`SAYANGKU`, `MAUGACHA`, `CANTIK`, `ILOVEYOU`, `PAPDULU`).
- **Efek Suara & Confetti:** Efek suara sintesis otomatis (tanpa perlu file `.mp3` tambahan) serta tema **Dark Mode & Light Mode**.

## 🚀 Cara Pasang ke GitHub Pages
1. Ekstrak file `.zip` ini.
2. Buat repository baru di GitHub (misal: `love-gacha`).
3. Upload semua file (`index.html`, `style.css`, `app.js`, `README.md`) ke root repository.
4. Masuk ke **Settings > Pages**, pilih branch `main` dan folder `/ (root)`, lalu klik **Save**.
5. Link website siap dikirim ke pasanganmu!
