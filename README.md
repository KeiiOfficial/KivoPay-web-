# Love Hub — Media Downloader, Profile Stalker, AI Chat & Love Gacha

Paket lengkap web statis siap upload langsung ke **GitHub Pages** (tanpa perlu server backend tambahan).

## Fitur Utama
1. **Media Downloader**: Mendukung CapCut, TikTok v2, Douyin, dan Facebook dengan pemutar video instan serta tombol unduh langsung.
2. **Profile Stalker**: Cek detail profil, avatar, bio, ID, verifikasi, dan statistik akun TikTok & Twitter.
3. **AI Chat & Tools**: Terintegrasi dengan auto-fallback 3 endpoint Siputzx (`gptoss120b` → `glm47flash` → `metaai`) tanpa perlu input API key manual.
4. **Love Gacha & Match**: Spin kartu takdir harian (1x / 5x Combo) + kalkulator kecocokan nama + penyimpanan koleksi otomatis di browser.
5. **Dark Mode & Light Mode**: Responsif penuh di HP maupun desktop.

## Cara Upload ke GitHub Pages
1. Ekstrak seluruh isi file `.zip` ini (`index.html`, `style.css`, `app.js`, `README.md`).
2. Buka repositori GitHub kamu (misalnya `KivoPay-web-`), hapus file lama jika perlu, lalu upload keempat file tersebut ke folder utama (`root`).
3. Pastikan file `index.html` berada di posisi paling luar (bukan di dalam sub-folder).
4. Tunggu 1–2 menit lalu *hard refresh* browser HP kamu agar tampilan baru langsung muncul.
