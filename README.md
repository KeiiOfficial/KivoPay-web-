# Love Hub v14 — by Keii Official

Aplikasi web all-in-one siap host di GitHub Pages dengan latar belakang video anime via link langsung (`https://files.catbox.moe/ngfcr9.mp4`).

## Fitur Utama
- **Anime Video Background (Direct Link) + Toggle (`🎬`)**: Memutar video latar belakang langsung dari URL Catbox tanpa perlu menyimpan file `.mp4` besar di repository.
- **Media Downloader**: CapCut, TikTok v2, Douyin, dan Facebook (HD tanpa watermark + info kreator).
- **Profile Stalker**: Cek profil TikTok & Twitter/X lengkap dengan multi-source fallback.
- **AI Chat**: Antarmuka bergaya WhatsApp dengan auto-fallback (`gptoss120b` → `glm47flash` → `metaai`).
- **Love Gacha & Match**: Spin kartu gacha & kalkulator kecocokan nama.
