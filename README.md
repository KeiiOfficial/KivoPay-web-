# Love Hub v12 — by Keii Official

Aplikasi web all-in-one siap host di GitHub Pages dengan latar belakang video anime (`assets/bg-anime.mp4`).

## Fitur Utama
- **Anime Video Background + Toggle (`🎬`)**: Latar belakang video anime full-screen dengan *overlay* adaptif (Dark/Light mode) serta tombol cepat di pojok kanan atas untuk menyalakan/mematikan video.
- **Media Downloader**: CapCut, TikTok v2, Douyin, dan Facebook (HD tanpa watermark + info kreator).
- **Profile Stalker**: Cek profil TikTok & Twitter/X lengkap dengan multi-source fallback.
- **AI Chat**: Antarmuka bergaya WhatsApp dengan auto-fallback (`gptoss120b` → `glm47flash` → `metaai`).
- **Love Gacha & Match**: Spin kartu gacha & kalkulator kecocokan nama.
