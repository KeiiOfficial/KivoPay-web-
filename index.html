Pertanyaan Umum (FAQ)

Informasi seputar penggunaan aplikasi web ini, fitur yang tersedia, dan identitas pengembang.

Siapa developer aplikasi ini?

Aplikasi web ini dikembangkan dan dikelola oleh Keii Official.

Apakah web ini gratis digunakan?

Ya, seluruh fitur (Media Downloader, Profile Stalker, AI Chat, dan Love Gacha) gratis digunakan tanpa login.

Kenapa video atau profil kadang gagal dimuat?

Biasanya karena tautan bersifat privat, link sudah kedaluwarsa, atau server API publik sedang padat. Coba ulangi beberapa saat lagi dengan link publik.

Kenapa balasan AI dibuat singkat?

Jawaban AI diatur singkat dan langsung ke inti agar tidak terpotong di tengah kalimat, dengan pergantian model otomatis jika server sibuk.

Apakah data chat dan gacha tersimpan aman?

Semua riwayat chat dan koleksi kartu gacha disimpan lokal di browser perangkat kamu (LocalStorage) dan tidak dikirim ke pihak lain.

Bagaimana cara menghubungi developer?

Kamu bisa menghubungi Keii Official melalui halaman GitHub resmi atau kanal sosial media pengembang.
